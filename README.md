# ☁️ EPAM Bootcamp Tasks

### Bir istekle başlayan yolculuk, bulutta birbirine bağlanan sistemlere dönüşür.

Bu repo, EPAM Bootcamp boyunca geliştirdiğim AWS odaklı görevleri bir araya getiriyor. Lambda ile başlayan çalışmalar; API’ler, mesajlaşma servisleri, veritabanları, gözlemlenebilirlik ve veri işleme senaryolarıyla ilerliyor.

> **13 görev · Farklı AWS servisleri · Uçtan uca uygulama deneyimi**

---

## 🧭 Yol Haritası

| Görev | Odak noktası |
|---|---|
| **task01** | Temel uygulama ve sandbox yapılandırması |

| **task13** | AppSync veri kaynağı dağıtımı |

## 🧩 Bu Repoda Neler Var?

**API geliştirme:** Lambda Function URL ve API Gateway ile servisleri dış dünyaya açma.

**Olay güdümlü mimari:** SQS, SNS ve DynamoDB Streams ile servisler arasında veri akışı kurma.

**Veri katmanı:** DynamoDB, Aurora ve AppSync üzerinden farklı veri erişim yaklaşımlarını uygulama.

**Geliştirici deneyimi:** Lambda Layers, X-Ray ve Swagger UI ile yeniden kullanılabilirlik, izleme ve API keşfi üzerine çalışma.

## 🚀 Başlarken

Her görev kendi klasöründe yer alır. İncelemek istediğiniz senaryo için ilgili `taskXX` dizinine geçin ve o görevin dosyalarındaki kurulum ve dağıtım adımlarını takip edin.

AWS kaynaklarını dağıtmadan önce hesabınızın ve gerekli sandbox yapılandırmasının hazır olduğundan emin olun. Kullanım sonrasında kaynakları kaldırmayı unutmayın; aktif AWS servisleri maliyet oluşturabilir.
